# Dave Thomas & Andy Hunt (The Pragmatic Programmers)

Authors, publishers (Pragmatic Bookshelf). Hunt is an Agile Manifesto signatory.

## Books in This List

- [[books/The Pragmatic Programmer]]

## Key Contributions

- Named DRY (Don't Repeat Yourself)
- Named rubber duck debugging
- Tracer bullets, orthogonality, software entropy / broken windows
- Founded Pragmatic Bookshelf (published many authors on this list)
- Thomas popularized Ruby in the West (*Programming Ruby*)

## Connections

- Hunt is an Agile Manifesto co-signatory
- DRY connects to [[authors/Martin Fowler|Fowler]]'s refactoring motivation
- Pragmatic Bookshelf published books by many figures in this vault
