# Edsger W. Dijkstra

Turing Award recipient (1972). Pioneer of structured programming and formal methods.

## Books in This List
- [[books/A Discipline of Programming]]

## Key Contributions
- "Go To Statement Considered Harmful" — structured programming advocacy
- Dijkstra's algorithm (shortest path)
- Semaphores (concurrency primitives)
- Coined "separation of concerns"
- ~1300 EWD manuscripts

## Connections
- [[authors/Donald Knuth|Knuth]]'s nuanced response to GOTO paper
- Both [[authors/Fred Brooks|Brooks]] and Dijkstra address complexity (management vs. mathematics)
- [[authors/Robert C Martin|Martin]]'s Clean Architecture layering echoes Dijkstra's THE system
