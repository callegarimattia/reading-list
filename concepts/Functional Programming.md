# Functional Programming

A programming paradigm that treats computation as the evaluation of mathematical functions. Emphasizes immutability, pure functions, and composition.

## Core Ideas

- Pure functions (no side effects)
- Immutable data
- Function composition
- Higher-order functions
- Pattern matching

## Relationship to Other Concepts

- Alternative to [[concepts/Object-Oriented Design]]
- [[concepts/Design Patterns]] look different in FP (many GoF patterns dissolve)
- [[concepts/Refactoring]] applies but with different techniques
