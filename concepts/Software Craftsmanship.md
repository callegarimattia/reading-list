# Software Craftsmanship

A movement emphasizing that software development is a craft requiring skill, discipline, and continuous improvement. Championed by [[authors/Robert C Martin|Robert C. Martin]] and the Pragmatic Programmers.

## Core Ideas
- Code quality as professional responsibility
- Continuous practice and learning
- Boy Scout Rule ("leave code cleaner than you found it")
- Professionalism in estimation, communication, and collaboration

## Relationship to Other Concepts
- Builds on [[concepts/Agile]] values with emphasis on technical excellence
- [[concepts/Refactoring]], [[concepts/Test-Driven Development]] as core craft practices
- [[concepts/Code Smells]] as the craftsman's diagnostic tool
