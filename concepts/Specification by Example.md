# Specification by Example

A set of process patterns that use concrete examples to define requirements, build shared understanding, and produce executable specifications that serve as [[concepts/Living Documentation|living documentation]].

## Core Ideas
- Use real examples to specify behavior (not abstract requirements)
- Collaborate to discover the right examples
- Automate examples as tests
- Refine specifications into a documentation system
