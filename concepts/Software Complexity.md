# Software Complexity

The fundamental challenge of software engineering. [[authors/Fred Brooks|Brooks]] distinguished between essential complexity (inherent in the problem domain) and accidental complexity (introduced by our tools and techniques).

## Core Ideas
- Essential vs. accidental complexity (Brooks, 1986)
- "No Silver Bullet" — no single technique yields 10x improvement
- Managing complexity is the primary job of software design
- Separation of concerns (Dijkstra) as a complexity management tool
