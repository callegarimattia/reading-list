# Test-Driven Development

Write a failing test, make it pass, refactor. The Red-Green-Refactor cycle.

## Core Ideas
- Tests drive design, not just verify it
- Small incremental steps
- Refactoring is a first-class activity
- Confidence to change code

## Relationship to Other Concepts
- [[concepts/Behavior-Driven Development]] evolved from TDD, focusing on behavior over implementation
- TDD operates at the unit level; [[concepts/Acceptance Testing]] operates at the feature level
- Both TDD and BDD share the test-first philosophy
