# Behavior-Driven Development

BDD is a collaborative approach to software development that bridges the gap between business stakeholders and technical teams. It extends [[concepts/Test-Driven Development|TDD]] by writing tests in natural language that describe *behavior* rather than implementation.

## Core Ideas

- Tests describe behavior, not implementation
- Use [[concepts/Ubiquitous Language|ubiquitous language]] shared by all stakeholders
- Given-When-Then scenario structure
- Discovery through [[concepts/Three Amigos|Three Amigos]] conversations
- Scenarios become [[concepts/Living Documentation|living documentation]]
