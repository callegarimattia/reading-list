# DevOps

A movement and set of practices that unify software development (Dev) and IT operations (Ops). Extends [[concepts/Agile|agile]] principles through deployment and production.

## Core Ideas

- The Three Ways: flow, feedback, continual learning
- Continuous delivery / deployment pipelines
- Infrastructure as code
- DORA metrics (deployment frequency, lead time, MTTR, change failure rate)
- "You build it, you run it"

## Relationship to Other Concepts

- Extends [[concepts/Agile]] and [[concepts/Extreme Programming]] to operations
- Continuous integration from XP evolved into CI/CD pipelines
- [[concepts/Software Architecture]] decisions constrain deployment options
