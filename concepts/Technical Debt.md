# Technical Debt

A metaphor coined by [[authors/Ward Cunningham|Ward Cunningham]] (1992): deliberate shortcuts in code that incur future cost, like financial debt incurs interest.

## Core Ideas
- Deliberate debt: shortcuts taken knowingly for speed
- Inadvertent debt: mess from lack of skill or understanding
- Interest: the ongoing cost of working around the debt
- Paying down debt: [[concepts/Refactoring]]
