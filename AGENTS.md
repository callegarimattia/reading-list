# AI Agent Instructions

This repo has an Obsidian vault (`vault/`) with software engineering books, authors, and concepts.

## Getting Started

1. Read `.agents/conventions.md` — vault rules, templates, and procedures
2. Read `.agents/knowledge-map.md` — the full relationship graph between books, authors, and concepts

## Available Tasks

| Task | Instructions |
| ---- | ------------ |
| Add a book | `.agents/add-book.md` |
| Summarize a book | `.agents/summarize-book.md` |

## Key Paths

- `vault/` — the Obsidian vault (all content lives here)
- `vault/books/` — one page per book
- `vault/authors/` — one page per author
- `vault/concepts/` — one page per concept
- `vault/Reading List.md` — master index
