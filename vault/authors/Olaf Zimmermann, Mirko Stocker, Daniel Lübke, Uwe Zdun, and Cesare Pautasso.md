# Olaf Zimmermann, Mirko Stocker, Daniel Lübke, Uwe Zdun, and Cesare Pautasso

Academic and industry researchers specializing in API design, service-oriented architecture, and software patterns. Based at universities and research institutions across Switzerland, Germany, and Austria.

## Books in This List

- [[books/Patterns for API Design]]

## Key Contributions

- Microservice API Patterns (MAP) pattern language
- API design decision modeling
- Message exchange pattern classification

## Connections

- Extends the pattern tradition of [[authors/Gang of Four|GoF]]'s [[books/Design Patterns]]
- Complements [[authors/Martin Fowler|Fowler]]'s [[books/Patterns of Enterprise Application Architecture]]
- Patterns apply to [[authors/Sam Newman|Newman]]'s microservices context
