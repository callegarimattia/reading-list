# Len Bass, Paul Clements, and Rick Kazman

Researchers at the Software Engineering Institute (SEI). Defined the quality-attribute-driven approach to software architecture and the ATAM evaluation method.

## Books in This List

- [[books/Software Architecture in Practice]]

## Key Contributions

- Quality attribute scenarios and tactics
- Architecture Tradeoff Analysis Method (ATAM)
- SEI's systematic approach to architecture evaluation

## Connections

- Academic foundation that [[authors/Robert C Martin|Martin]]'s _Clean Architecture_ and [[authors/Martin Fowler|Fowler]]'s enterprise patterns build upon
