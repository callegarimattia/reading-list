# Code Smells

Surface indicators that something may be wrong in the code — not bugs, but structural issues that make code harder to understand or change.

## Core Ideas

- Named smells: Long Method, Large Class, Feature Envy, Shotgun Surgery, etc.
- Smells suggest refactorings (each smell has a corresponding fix)
- Heuristic, not prescriptive
