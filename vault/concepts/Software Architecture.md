# Software Architecture

The high-level structure of a software system — component boundaries, communication patterns, and the decisions that are hard to change later.

## Core Ideas

- Architecture is about the decisions that matter most
- Dependency management (which components know about which)
- Trade-offs (monolith vs microservices, consistency vs availability, etc.)
- Layered, hexagonal, clean, event-driven architectures
