# Ubiquitous Language

A shared vocabulary between developers and domain experts, used consistently in code, tests, and conversation. Originally from Domain-Driven Design (Eric Evans).

## Core Ideas

- One language shared by all team members
- Used in code, tests, documentation, and conversation
- Reduces translation errors between business and tech
- Evolves as understanding deepens
